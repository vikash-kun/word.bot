# 📖 WordBot - Personal Dictionary Assistant

WordBot is a simple Python dictionary chatbot that helps users learn word meanings. It supports technology terms, common English words, daily-life vocabulary, and words from multiple languages such as Japanese, Hindi, Spanish, French, and German.

## Features

* ✅ 200+ predefined word meanings
* ✅ Simple chatbot conversation
* ✅ Small talk support
* ✅ Case-insensitive input
* ✅ Friendly user interaction
* ✅ Exit anytime using commands like `bye`, `exit`, or `quit`
